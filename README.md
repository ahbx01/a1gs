# A1 Global Sourcing – Website

Professional single-page website for **A1 Global Sourcing** (China-Based Sourcing Partner).

## What’s Included

- Sticky navigation
- Hero section with key value props
- About section
- Full services grid (Sourcing + Marketing/Consulting)
- 3 package tiers (placeholders – customize pricing & features)
- Clear 4-step process
- Client testimonials (placeholders – replace with real ones)
- Strong CTA banner
- Contact section with all your details + form
- Responsive design (mobile-friendly)
- Deep navy + gold professional theme

## How to Use

1. **Preview locally**  
   Open `index.html` in any modern browser (Chrome, Safari, Edge, Firefox).

2. **Host it**  
   - Upload the folder to any web host (Netlify, Vercel, Cloudflare Pages, GitHub Pages, or traditional hosting).  
   - For Netlify/Vercel: just drag & drop the folder or connect a Git repo.

3. **Customize**  
   - Edit text, packages, and testimonials directly in `index.html`.  
   - Replace placeholder stats and reviews with real ones.  
   - Contact form currently opens the user’s email client (mailto). For a real form backend, connect Formspree, Netlify Forms, or similar later.
